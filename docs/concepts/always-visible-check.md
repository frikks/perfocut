# Концепты: «Проверка под лазер» всегда перед глазами

Исходная трёхколоночная компоновка признана лучшей. Все варианты ниже **сохраняют её** и решают одну задачу: блок `Проверка под лазер` (`Store.stats.warnings` / `ok-line`) не должен уезжать из поля зрения при прокрутке правой панели.

**Выбран и реализован локально (без публикации в git): концепт 2 — диагностическая лента.** Включена по умолчанию. `F6` или сегмент «Проверка под лазер» в настройках переключают «Как было / Лента». Остальные концепты в сборку не включены.

Старый блок ошибок из панели «Итог» удалён — полный список теперь раскрывается кнопкой ▼ в ленте. Дополнительно добавлены:
- детектор наложений отверстий (`gen::analyze_overlaps`, spatial hash) с координатами маркеров и кнопка «Убрать наложения» в ленте (`gen::fix_overlaps`: уменьшение размеров и увеличение шага);
- маркеры наложений рисуются на чертеже, клик выбирает отверстие; в раскрытии ленты — «Удалить выбранное» (координата добавляется в `Params::excluded`, движок её больше не создаёт) и «Вернуть все»;
- исправлена высота холста на ПК: после удаления нижнего дока ветка `wide` исчезла, и холст занимал только 44% окна — схема уходила под чёрную область.
- исправление кнопки «Все» в шаблонах: подсветка категории теперь binding к `Store.template-category-index`, «Все» очищает и категорию, и поиск.

Сейчас блок находится внизу `SummaryPanel`, а правая панель — `Flickable` с `SummaryPanel + ExportPanel`. Поэтому при прокрутке к экспорту проверка исчезает.

## Концепт 1. «Закреплённый инспектор»

```
┌──────────────────────────────────────────────────────────┐
│ ШАПКА                                                    │
├────────────┬─────────────────────────────┬───────────────┤
│ Настройки  │                             │ ▣ ПРОВЕРКА    │ ← закреплено
│ Шаблоны    │          ХОЛСТ              │   ● ошибок нет│   (не скроллится)
│            │                             │ ──────────────│
│            │                             │ Итог (скролл) │
│            │                             │ Экспорт       │
└────────────┴─────────────────────────────┴───────────────┘
```

- Правая панель делится на **две зоны**: верхняя фиксированная (проверка) и нижняя прокручиваемая (итог + экспорт).
- При появлении ошибок верхняя зона вырастает до 4 строк; остальной список — во внутреннем скролле этой же зоны.
- Зелёная/красная кромка верхней зоны дублирует статус без чтения текста.

**Плюсы:** минимальное изменение, проверка физически не может скрыться; привычная IDE-логика.
**Минусы:** отнимает ~120–160 px высоты у правой панели.
**Оценка:** 9/10. **Сложность:** низкая.

## Концепт 2. «Диагностическая лента»

```
┌──────────────────────────────────────────────────────────┐
│ ШАПКА                                                    │
├──────────────────────────────────────────────────────────┤
│ ● ПРОВЕРКА: 2 ошибки — перемычка 1.8 мм < 2.0 мм   [▼]  │ ← лента 32px
├────────────┬─────────────────────────────┬───────────────┤
│ Настройки  │          ХОЛСТ              │ Итог          │
│ Шаблоны    │                             │ Экспорт       │
└────────────┴─────────────────────────────┴───────────────┘
```

- Тонкая полоса под шапкой на всю ширину окна. Всегда видна, в том числе в режиме «холст на весь экран».
- Зелёная — ошибок нет; янтарная — предупреждения; красная — критично. Клик раскрывает полный список.
- В правой панели полный блок проверки остаётся на месте.

**Плюсы:** максимальная заметность; не трогает структуру панелей; работает на всех платформах.
**Минусы:** занимает вертикальное место над холстом; при длинном тексте нужно сокращать.
**Оценка:** 8/10. **Сложность:** низкая/средняя.

## Концепт 3. «Значок на углу холста»

```
┌──────────────────────────────────────────────────────────┐
│ ШАПКА                                          ┌────────┐│
├────────────┬─────────────────────────────┐     │● 2.err ││ ← плавающий
│ Настройки  │          ХОЛСТ              │     └────────┘│   бейдж
│ Шаблоны    │                             │               │
│            │                             │ Итог /Экспорт │
└────────────┴─────────────────────────────┴───────────────┘
```

- Компактный бейдж в правом верхнем углу холста: цветная точка + число ошибок.
- Клик открывает поповер со списком `warnings`.
- В правой панели — полный блок проверки как раньше.

**Плюсы:** не крадёт место у панелей; ошибка всегда в зоне внимания над листом; красиво смотрится в неоновой палитре.
**Минусы:** маленькая площадь — легко не заметить при рассеянном взгляде;popup надо правильно позиционировать.
**Оценка:** 8/10. **Сложность:** средняя.

## Концепт 4. «Нижний док диагностики»

```
┌──────────────────────────────────────────────────────────┐
│ ШАПКА                                                    │
├────────────┬─────────────────────────────┬───────────────┤
│ Настройки  │          ХОЛСТ              │ Итог          │
│ Шаблоны    │                             │ Экспорт       │
├────────────┴─────────────────────────────┴───────────────┤
│ ▣ ПРОБЛЕМЫ (2)  ● перемычка 1.8 мм < 2.0 мм   [свернуть] │ ← док
└──────────────────────────────────────────────────────────┘
```

- Зафиксированный док снизу на всю ширину, как панель «Problems» в IDE.
- Список ошибок с цветом по критичности, клик по строке подсвечивает место на холсте (если есть координаты).
- Сворачивается до полоски 28 px.

**Плюсы:** ошибки всегда видны и читаемы; естественно для технических пользователей.
**Минусы:** съедает высоту холста; для новичков может выглядеть «страшным».
**Оценка:** 9/10 для профи, 7/10 для новичков. **Сложность:** средняя/высокая.

## Концепт 5. «Вкладка Итог с живым бейджем»

```
┌──────────────────────────────────────────────────────────┐
│ Настройки  │  ХОЛСТ          │ [ Итог ●2 ] [ Экспорт ]   │
│ Шаблоны    │                 │ ⚠ перемычка 1.8 < 2.0 мм  │ ← 1 строка
│            │                 │ ... остальное скроллится │
└────────────┴─────────────────┴──────────────────────────┘
```

- Правая панель получает `Seg` «Итог | Экспорт», у вкладки «Итог» — цветной бейдж с числом ошибок.
- Под вкладками — одна всегда видимая строка с самой критичной ошибкой; полный список ниже.

**Плюсы:** очень маленькое изменение; бейдж мешает не заметить проблему.
**Минусы:** подробный список всё равно нужно открывать; при 5+ ошибках видна только первая.
**Оценка:** 7/10. **Сложность:** низкая.

---

## Идея на будущее (не отдельный концепт)

**Разметка проблем прямо на листе.** Для каждой ошибки, у которой есть координаты, рисовать на холсте цветной маркер/кольцо. Это требует, чтобы ядро возвращало не только строки предупреждений, но и координаты — отдельная задача.

## Рекомендация

Начать стоит с **концепта 1** (закреплённый инспектор): он сохраняет исходную компоновку почти без изменений и гарантирует, что проверка всегда на виду. Если хотите maximum заметности — **концепт 2** (лента) можно наложить поверх любого из остальных.

Откройте `docs/concepts/index.html` — там наглядные схемы всех пяти вариантов.
