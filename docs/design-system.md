# Дизайн-система PerfoCut

Единый источник правды для интерфейса — `app/ui/theme.slint`. Все цвета, размеры и состояния берутся отсюда; хардкод в компонентах допустим только для нейтральных служебных значений.

## Визуальный язык

«Техно-консоль»: шесть сменных палитр (HUD, Blueprint, Терминал, Осциллограф, Промышленная, AMOLED) с общим акцентом. У каждой — свой фон, панели и цвет сетки; графитовые панели с акцентной кромкой и моноширинные заголовки создают ощущение измерительного прибора.

Принципы (по скиллам hallmark, huashu-design, emilkowalski/skills):

- не использовать шаблонные приёмы: «скругление + цветная полоска слева», middot-связки, зевок над каждым заголовком, стрелки на кнопках;
- тени полупрозрачные, а не сплошные границы;
- анимации выхода/входа — `ease-out`, без лишних задержек;
- текст должен выдерживать длинные значения: `elide` в заголовках, перенос в подсказках с гарантированной высотой;
- Каждый интерактивный элемент имеет роль и подпись для скринридеров; фокус с клавиатуры не требует дополнительного нажатия на сенсорном экране.

## Источник: Open Design

Лендинг (`index.html`) и приложение (`app/ui/`) оформлены по дизайн-системе **Open Design `neon`** (локально: `C:\Users\frikks\AppData\Local\Programs\Open Design\resources\open-design\design-systems\neon\DESIGN.md`). Лазерная резка ↔ светящийся луч — прямой смысловой мотив. Взятые правила:

- глубокий фиолетово-чёрный фон `#090513` / `#0D081F`, панели `#171029` / `#1E1636`, кромки `#3B2E66`;
- первичный лаймовый луч `#B8FF3D`, вторичный лазерно-циановый `#00E5FF`, текст `#F4F1FF` / `#BCB4DB`;
- свечение вместо теней: `text-shadow` у заголовков, `box-shadow` у кнопок, glow-кромки карточек;
- моноширинные значения (`JetBrains Mono`) и подписи с трекингом (`Inter`);
- component data tile — полоса показателей под hero;
- motion только для сигналов, `prefers-reduced-motion` уважается.

### Приложение (`app/ui/`)

- режим `HUD` (0): `#090513` / `#0D081F` / `#171029` / `#1E1636` / `#2E2152`, сетка `#2A1F4D`, текст `#F4F1FF` / `#BCB4DB` / `#857CB4`;
- акцент 0 — лаймовый `#B8FF3D`, производные `#D4FF80`, `#9BE32C`, `#8FD420`; отдельный токен `neon-cyan` `#00E5FF` для холодных кромок;
- радиусы 8px / 12px — мягкие углы, чтобы свечение выглядело цельно;
- главная кнопка — плоская лаймовая заливка в циановом контуре; подписи групп — Inter с трекингом, значения — только моно;
- линия в шапке и кромки карточек итогов (`Stat`) дышат через `Timer` + `animate opacity` — единственная декоративная анимация;
- семантические цвета: ok `#39FF88`, warn `#FFB020`, alert `#FF3D6E`.

Остальные пять тем и пять акцентов не изменены.

| Токен | Назначение |
| :--- | :--- |
| `bg0`, `bg`, `card`, `raised`, `raised2` | уровни фона шести техно-тем (`mode` 0–5) |
| `glass-strong`, `glass-edge`, `glass-shadow` | полупрозрачные слои и тень сплеша |
| `shell`, `shell-raised` | оболочка активной техно-темы |
| `panel`, `panel-edge`, `panel-ink`, `panel-muted`, `panel-bar` | панели, их кромка, текст и акцентная полоса |
| `grid-line` | линии сетки на холсте |
| `glass-edge`, `glass-shine`, `glass-shadow` | кромка, блик, тень |
| `t1`, `t2`, `t3` | основной, второстепенный и приглушённый текст |
| `acc`, `acc-hover`, `acc-ink`, `acc-text`, `acc-soft`, `glow` | акцент и его производные |

## Компоненты

- **Btn** — три вида (обычная, главная, без фона), `framed` для рамки, фокус с клавиатуры, `accessible-role: button`.
- **Seg** — переключатель вариантов; `animated: true` включает плавно переезжающий индикатор.
- **FieldRow / NumField / TextField** — пары «подпись — поле»; фокус подсвечивается акцентным кольцом.
- **Section** — сворачиваемая стеклянная карточка; заголовок с шевроном и `elide`.
- **Stat** — карточка итога с акцентной линией.
- **Modal** — стеклянное окно с тенью и верхним свечением; закрывается по фону и Esc.
- **Splash** — технологичная матрица со сканирующим лучом (только Slint-элементы и `animation-tick()`).

## Адаптив

- `wide` (≥960 px) — три колонки; `medium` (760–1200 px) — уже панели, больше холста; ниже 960 px — вкладки.
- На телефоне `Theme.touch` увеличивает строки и поля, не ломая компактность; учитываются safe-area insets.
- Системный масштаб шрифта Android ограничен диапазоном 0.72–1.35.
