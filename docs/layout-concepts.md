# Варианты компоновки экрана PerfoCut

Три принципиально разных подхода к расположению элементов. Общая цель — сохранить всю логику и обработчики, менять только визуальную структуру.

## Вариант A. «Студия» — рабочее место оператора

```
┌──────────────────────────────────────────────────────────────┐
│ ШАПКА: лого · Открыть · Заказ · Экспорт · [панели] · шестерня │
├──┬──────────┬───────────────────────────────┬────────────────┤
│Р│ Левая    │                               │ Инспектор      │
││ панель   │         ХОЛСТ                  │ • Итоги        │
│а│ Настройки│      (перфорация)             │ • Экспорт      │
││ Шаблоны  │                               │ • Слои         │
││          │                               │                │
├──┴──────────┴───────────────────────────────┴────────────────┤
│ СТАТУС: отверстия · открытая площадь · рез · время · цена     │
└──────────────────────────────────────────────────────────────┘
```

- **Левый рельс** — быстрый переключатель разделов (иконки).
- **Левая панель** — «Изображение», «Лист», «Узор», «Металл», «Шаблоны».
- **Холст** — всегда в центре, масштабируется, принимает перетаскивание файлов.
- **Инспектор справа** — только результаты и экспорт; сворачивается кнопкой.
- **Статус-бар внизу** — живые моно-значения из `Store.stats`.

**Для кого:** операторы лазера, которые каждый день работают с десятками заказов и привыкли к CAD-среде.
**Юзабилити для новичков:** 7/10 — всё на виду, но плотность высокая.

## Вариант B. «Мастер» — пошаговый сценарий

```
┌──────────────────────────────────────────────────────────────┐
│ 1 Картинка → 2 Узор → 3 Металл → 4 Результат   [Предпросмотр]│
├────────────────────────────────────┬─────────────────────────┤
│ ШАГ 2: выберите узор               │ ПРЕДПРОСМОТР (всегда    │
│ [сетка] [размер] [шаг]             │ виден, мини-карточка    │
│ [18 шаблонов с превью]             │ + цифры)                │
│                                    │                         │
│ ← Назад                 Далее →    │                         │
└────────────────────────────────────┴─────────────────────────┘
```

- **Верхний степпер** — четыре шага, возврат в любой момент.
- **Основная область** — только настройки текущего шага.
- **Правая колонка** — постоянный предпросмотр и три ключевых числа.

**Для кого:** новички, разовые заказы, обучение, демонстрации.
**Юзабилити для новичков:** 9/10 — нельзя заблудиться, но опытному пользователю придётся кликать больше.

## Вариант C. «Кокпит» — холст на весь экран

```
┌──────────────────────────────────────────────────────────────┐
│                 ХОЛСТ НА ВСЁ ОКНО                            │
│  ┌── Выдвижная панель слева ┐        ┌─ Инспектор справа ─┐  │
│  │ Настройки / Шаблоны      │        │ Итоги / Экспорт    │  │
│  └──────────────────────────┘        └────────────────────┘  │
│           [панели выезжают по краю, холст не сжимается]      │
└──────────────────────────────────────────────────────────────┘
```

- **Холст** — занимает 100% окна, панели накладываются стеклом.
- **Выдвижные панели** — появляются по кнопке на краю, автоматически скрываются.
- **Мини-тулбар** — плавает над холстом (масштаб, сетка, цвета).

**Для кого:** дизайнеры и художники, крупные изображения, работа на широком мониторе.
**Юзабилити для новичков:** 6/10 — красиво и просторно, но неочевидно, куда девались настройки.

## Переиспользуемые компоненты (Slint вместо TSX)

| В промте | В проекте | Файл |
| :--- | :--- | :--- |
| `Button.tsx` | `Btn` | `app/ui/widgets.slint` |
| `Slider.tsx` | `NumField` + `Slider` | `app/ui/widgets.slint` |
| `Layout.tsx` | `Header` + `Stage` + панели | `app/ui/app.slint` |
| — | `Caption`, `Seg`, `Modal`, `Hint` | `app/ui/widgets.slint` |

Логика (`Store` и обработчики в `app/src/app.rs`) не меняется: только визуал и структура Slint-элементов.

## Выбор для pre.5

Реализован **вариант A «Студия»**: он сохраняет всю текущую логику, даёт заметный выигрыш пространства за счёт статус-бара и сворачиваемого инспектора и одинаково хорошо работает на Windows, Android и в вебе.
