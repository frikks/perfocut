## P0 — исправить в первую очередь

### 1. APK подписан публичным тестовым ключом
**Инфраструктура, Critical.** `android/build.sh:17-18,46-50`, `.github/workflows/release.yml:68-75`.
`ANDROID_KEYSTORE_B64` в секретах репозитория отсутствует (`total_count: 0`), поэтому CI всегда падает назад на `android/test.keystore.b64` с паролем `android`. Сертификат всех APK — `CN=PerfoCut Test`. Подпись не защищает от подмены.
**Fix (отложен):** сгенерировать production-keystore, завести секреты, убрать fallback в релизной ветке (`[ -n "$ANDROID_KEYSTORE_B64" ] || exit 1`), перевыпустить APK с уведомлением о смене ключа. **Решение пользователя: пока НЕ менять ключ** — иначе Android откажется ставить новую сборку поверх уже установленной (INSTALL_FAILED_UPDATE_INCOMPATIBLE). План: донести смену ключа до стабильного релиза 0.5.0, заранее предупредить пользователей, что перед установкой нужно удалить старую версию (и выгрузить заказы через `.perfo`, чтобы не потерять данные). versionCode при этом уже можно делать монотонным — см. P1.

### 2. Зависание при больших `offset_x`/`offset_y`
**Ядро, Critical.** `core/src/params.rs:219-267`, `core/src/gen.rs:1231-1237,1273-1277`.
`sanitized()` не ограничивает смещения. Для обычной сетки `est` от них не зависит, защита `MAX_SHAPES` не срабатывает, а `reach` растёт до триллионов — генерация не завершается.
**Fix (pre.12):** `sanitized()` ограничивает `offset_x/y` величиной листа ×4; углы нормализуются, цены — неотрицательные. Добавлен тест с `offset = 1e12`.

### 3. Паника при `clamp(min > max)` в недорезах и M-joint
**Ядро, Critical.** `core/src/export.rs:91`, `core/src/export.rs:175`, `core/src/gen.rs:1587`.
`tab_w.clamp(0.01, per/(2n))` и `gap.clamp(0.01, step*0.8)` паникуют при слишком маленьком листе/крупном числе недорезов. Состояние достижимо из UI (`tab_n` до 9999).
**Fix:** `let hi = ...; value.clamp(hi.min(0.01), hi)` либо пропускать M-joint, если шаг < 0.013 мм.

### 4. История заказов не работает
**UI, Critical.** `app/src/app.rs:630-639`, `app/src/platform/desktop.rs:23-26`.
В `on_open_recent` найденный путь выбрасывается (`let _ = path`), а `remember_order()` сохраняет только имя файла, а не путь. Клик по «недавнему заказу» показывает тост и ничего не открывает.
**Fix:** хранить полный путь, в колбэке читать файл и вызывать `open_bytes` вне `with()` (иначе реентерабельный `borrow_mut` молча проигнорируется).

## P1 — сильно влияет на UX и корректность

### Ядро
- **SVG-path с M-joint битый** (`export.rs:435-439`): `d="ML123 456..."` — команда `M` без координат. **Исправлено** (pre.11): `M{x} {y}` + `L` для остальных точек.
- **G-code `origin=tl` — отрицательный Y** (`export.rs:533-537`): `Y = y - h`. **Исправлено** (pre.11): введён множитель `sy = -1`, возврат в ноль идёт в `(0,h)` листа.
- **`cap` не учитывает `grid_aspect` и `mosaic`** (`gen.rs:906-916`): **Исправлено** (pre.11): минимальный шаг `rect = pitch*aspect`, `mosaic = 0.8*pitch`, остальные сетки сохраняют прежний `pitch`.
- **Вытянутые фигуры считаются по ширине** (`gen.rs:601-667,1394,1463`): **Исправлено** (pre.12) — номинальный диаметр ограничивается как `cap / max(1, shape_aspect)`.
- **Блокировка UI при пакетной обработке и открытии файлов** (`desktop.rs:85-117`, `app.rs:1265-1287`): всё делается в потоке Slint. Вынести в thread + `invoke_from_event_loop`.

### Платформы
- **Android: потеря колбэка при отмене picker** (`android.rs:84-93`, `MainActivity.java:188`): `RESULT_CANCELED` не вызывает нативный колбэк, `FnOnce` остаётся в слоте; два быстрых вызова перезаписывают друг друга. Всегда отправлять пустой результат, добавить `requestId`.
- **`readUri()` без лимита и без `finally`** (`MainActivity.java:157-175`): OOM на больших файлах и утечка FD при ошибке. `try-with-resources` + лимит размера.
- **Недавние заказы / несколько аргументов CLI / drop нескольких файлов** (`desktop.rs:47-56`, `web.rs:142-151`): обрабатывается только первый файл.
- ** settings.json.tmp с фиксированным именем** (`desktop.rs:180-190`, `android.rs:172-181`): гонка между экземплярами.
- **Обновление скачивается прямо в `.exe`** (`desktop.rs:211-253`): битый файл при обрыве, нет проверки хэша. Качать в `.part`.
- **Android < 29: сообщение «Скачано в Загрузки» неправда** (`MainActivity.java:250-257`): файл в приватном каталоге.

### UI
- **Материал всегда подсвечивает «Своё»** (`panels.slint:965-975`, `current: 7` константа). Завести `Store.material-current`.
- **Цвет листа/фона недоступен при ширине 960–1175 и на телефоне** (`app.slint:478,529-558`): `roomy` зависит от ширины stage. Показывать Swatch всегда.
- **Модалка настроек не скроллится** (`widgets.slint:609-689`): на высоте 360 px нижние блоки недоступны. Обернуть в `Flickable`.
- **`Par` и `Params` рассинхронизированы** (`app.rs:952-981`): UI показывает 5 мм, ядро использует 10 (`sanitized()`). Применять `sanitized()` в `set_params`.
- **Пропорции листа не обновляются при шаблоне** (`app.rs:535-546`): при `lock_ratio` новое отношение не пересчитывается.
- **WASM: генерация в потоке UI** (`app.rs:1399-1404`). **Исправлено** (pre.13): отдельный wasm-модуль `worker/`, генерация в Web Worker, результат возвращается через `wasm_bindgen.worker_result`. Проверено в реальном браузере через CDP — воркер отвечает JSON результата.
- **Перерисовка выделяет до ~225 МБ на кадр** (`render.rs:258-285`, `app.rs:1613-1649`): переиспользовать pixmap/mask, добавить culling в `hole_path`.

### Инфраструктура
- **Скриншоты CI не попадают на Pages** (`release.yml:98-101`, `pages.yml:9,35`): пишутся в `docs/screenshots/`, Pages берёт корневой `screenshots/`, плюс `[skip ci]`. Сайт показывает старые картинки.
- **Нет `concurrency` в release.yml** — гонки `workflow_dispatch` и push, оба создают один тег.
- **Одинаковый `versionCode=405` у всех пререлизов 0.4.5** (`android/build.sh:14-16`) — Android не обновит APK. **Исправлено:** код теперь включает номер пререлиза (`0.4.5-pre.9` → `4509`).

## P2 — качество и мелкие баги

- `Shape::start()` паникует на пустом `Poly` (`gen.rs:40-45`); `Gray::mean` паникует на 0×0 (`image.rs:38-41`).
- ZIP-ридер не проверяет CRC (`zip.rs:116-126`).
- `sanitized()` не нормализует цены и углы — NaN в стоимости без предупреждения (`params.rs:219-267`).
- `hole_shapes` определяет монтажные отверстия «последними N» (`export.rs:215-227`) — при ручном удалении логика слоёв ломается.
- STEP: двойное выделение памяти и игнорирование слоёв (`lib.rs:31`, `export.rs:1177-1187`).
- Web: отмена выбора файла утекает `Closure` (`web.rs:39-83`); ошибка сохранения показывает имя файла (`web.rs:210-213`); разный формат времени в `.perfo` (`mod.rs:44-67` vs `web.rs:310-315`); popup-block не детектируется (`web.rs:224-233`).
- Две кнопки «Сбросить настройки» с разным поведением (`panels.slint:1398`, `app.slint:1493`); `reset()` не трогает темы/язык/форматы.
- Нет `accessible-*` у `Seg`, `Check`, `Slide`, `Swatch`, `Modal`.
- Непереведённые строки: названия материалов, «Все», «Аметист», «Русский» → `Russian`, дубль `msgid "Сбросить настройки"` в `.po:525,702`.
- `View.check-mode` не сохраняется между запусками (`store.slint:212`).
- Маркеры наложений кликабельны только при включённой ленте (до исправления), счётчик в ленте считает пары, а маркеры — уникальные отверстия.
- Документация противоречит коду: `docs/layout-concepts.md` утверждает, что A/B/C реализованы; `docs/concepts/index.html` говорит «в git не отправлялось», хотя файл закоммичен; «46 тестов» вместо 50; случайные CJK/CP1252-артефакты в README и Cargo.toml.
- `Cargo.lock` в `.gitignore`, но web-сборка читает из него версию wasm-bindgen.
- Дубли `.agents/skills` и `.github/skills`, три копии скриншотов, `index.html` == `docs/landing/index.html`, `skillfoxx-lock.json` в корне.
- Ссылки «Скачать» ведут на стабильную v0.4.4, хотя активная разработка — пререлизы.

## Исправлено в этой сессии

1. **Фильтр шаблонов**: `on_set_template_category`/`on_set_template_query` теперь пишут значения обратно в `Store` — поиск и категория больше не теряются, «Все» действительно очищает оба.
2. **Выбор наложения**: клик по маркеру теперь включает ленту; состояние выбора перенесено в `Store` и сбрасывается при каждом новом результате `show_stats()`, поэтому «Удалить выбранное» не может удалить устаревшее отверстие.
3. Ранее: маркеры ставятся в центры отверстий, порог удаления сужен до половины диаметра (pre.8).
